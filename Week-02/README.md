# 📖 Overview

Welcome to **Week 02** of the **Artificial Intelligence using Python** course.

This week builds upon the Python fundamentals learned previously and introduces some of the most important concepts in Python programming:

* Python Modules
* Object-Oriented Programming (OOP)
* File Handling
* Exception Handling

These concepts form the backbone of writing clean, reusable, and maintainable Python programs. They are also essential prerequisites for Machine Learning, Data Science, Deep Learning, and Artificial Intelligence projects that will be covered later in this course.

---

# 🎯 Learning Objectives

After completing this week's lectures and exercises, you will be able to:

* Import and use Python modules.
* Understand why Object-Oriented Programming is important.
* Create classes and objects.
* Use constructors (`__init__()`).
* Work with instance variables and instance methods.
* Apply encapsulation using public and private attributes.
* Implement getters and setters.
* Understand inheritance.
* Override methods in child classes.
* Understand polymorphism.
* Use Python special methods.
* Read from and write to files.
* Work with different file modes.
* Use context managers (`with` statement).
* Handle file-related exceptions.
* Understand Python exception handling.
* Use `try`, `except`, `else`, and `finally`.
* Raise built-in exceptions.
* Create custom exceptions.
