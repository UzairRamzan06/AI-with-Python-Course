### What I Learned

# Variables

### What I Learned

Variables are used to store data in memory.

Example:

```python
name = "Ali"
age = 22
```

### Rules

* Variable names should be meaningful.
* Variable names cannot start with a number.
* Use underscores instead of spaces.

# Conditional Statements

### What I Learned

Python uses:

# Lambda Functions

### What I Learned

Lambda functions are small anonymous functions written in a single line.

Example:

```python
square = lambda x: x * x
```

They are useful for short operations and are commonly used with functions like `map()`, `filter()`, and `sorted()`.
